# RAG overlay

These files come from the supplied `copilot.rag` implementation.

They intentionally depend on the existing repository modules:

- `copilot.konfigurasi`
- `copilot.llm.klien`
- `copilot.dokumen.pdf`

When this ZIP is overlaid onto the ODP-BNI repository, keep the repository's
existing `copilot` package and add/replace only the `copilot/rag/` files.
